# Security

Star Citizen Triple Screen is an external window-management script. Security
reports should be opened privately through GitHub's security-advisory feature.

The project intentionally excludes DLL injection, rendering hooks, process-memory
access, binary modification, EAC bypass logic, stealth, services, and drivers.
Do not propose changes that cross those boundaries.

No third-party tool can guarantee an anti-cheat outcome. Users should review the
plain-text PowerShell source and the anti-cheat notes before running a release.
