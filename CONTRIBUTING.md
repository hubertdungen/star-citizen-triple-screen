# Contributing

Bug reports, code review, and tested monitor layouts are welcome.

Please include:

- Windows version and GPU/driver family;
- Star Citizen channel and build;
- physical and effective resolution of each display;
- Windows scale percentage for each target display;
- monitor arrangement and the selected layout mode;
- the wrapper log and relevant display lines from `StarCitizen\\LIVE\\Game.log`,
  with account/session identifiers and unrelated personal paths removed.

Do not upload Star Citizen executables, game assets, authentication data, crash
dumps containing private data, or proprietary third-party binaries.

Changes must preserve the external-only safety boundary: no injection, graphics
hooks, game-memory access, binary patches, EAC bypasses, telemetry, services,
drivers, stealth, or automatic privilege elevation.
